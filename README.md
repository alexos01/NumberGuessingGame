# 🎮 Neon Guess | Interactive Number Guessing Game

A modern, highly interactive, and visually stunning web-based number guessing game. Instead of traditional "too high/too low" text, this game features a creative **"Temperature" hint system** (Freezing ➡️ Cold ➡️ Warm ➡️ Hot ➡️ Burning) to guide the player, wrapped in a sleek **Glassmorphism** UI with smooth animations.

## ✨ Features

- 🌡️ **Temperature Mechanic**: Get intuitive visual hints based on how close your guess is to the secret number.
- 🎯 **Dynamic Range Tracker**: The UI automatically updates the possible number range as you guess, helping you narrow down the answer.
- 🎨 **Glassmorphism UI**: A premium, modern dark-mode aesthetic with frosted glass effects and animated neon background blobs.
- 📱 **Fully Responsive**: Looks and works perfectly on desktops, tablets, and mobile devices.
- ⚡ **Micro-interactions**: Includes input glow effects, smooth slide-in feedback animations, and a "shake" animation for invalid inputs.
- 🏆 **Win State Transformation**: The UI elegantly transforms upon victory, offering a one-click "Play Again" experience.
- 🚀 **Zero Dependencies**: Built with pure HTML, CSS, and Vanilla JavaScript. No build tools, frameworks, or installations required.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and accessibility.
- **CSS3**: Custom properties (variables), `backdrop-filter` for glassmorphism, keyframe animations, and flexbox/grid layouts.
- **Vanilla JavaScript (ES6+)**: Game logic, DOM manipulation, and event handling.
